# Winter Village - Free Sample
StationSupply pixel series. Five native transparent ENDESGA-32 sprites on a 16px canvas grid:
snowy pine 48x64, gift 16x16, sled 32x16, wreath 16x16, snow patch 32x16.
Full pack: https://stationsupply.itch.io/winter-village-pixel-pack
Full pack contains 25 winter parts and props, 1x/2x/4x, sheet and an example street.
Generated with AI then converted to true pixel art, fitted and cleaned. Snow patch is derived.
